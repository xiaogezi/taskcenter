# 项目术语

## 一句话结论

ReqRadar 项目核心术语定义。

## 核心术语

### Codex

OpenAI 的代码执行 CLI 工具，用于执行代码任务。

### Session

Codex 会话，包含多轮对话和任务执行记录。

### Requirement

需求，从用户消息中提取的任务目标。

### Task

任务，Agent 执行的代码修改或操作。

### MCP

Model Context Protocol，模型上下文协议，用于 Agent 与外部工具通信。

### Ledger

任务账本，持久化任务状态和事件记录。

### Event

任务事件，记录任务状态变化。

## 状态术语

### 需求状态

| 状态 | 说明 |
|------|------|
| verified | 有代码/测试证据的验收 |
| in_progress | 正在实现 |
| partial | 部分实现 |
| missing | 未实现 |
| needs_validation | 待验证 |
| untriaged | 待整理 |

### 任务状态

| 状态 | 说明 |
|------|------|
| planned | 计划中 |
| in_progress | 进行中 |
| blocked | 阻塞 |
| done_claimed | 声称完成 |
| verified | 已验证 |
| cancelled | 已取消 |
| removed | 已移除 |

### Session 投递状态

| 状态 | 说明 |
|------|------|
| dry_run | 预演 |
| delivering | 投递中 |
| delivered | 已投递 |
| delivered_hidden | 已投递（隐藏） |
| failed | 失败 |
| queued | 排队中 |
| running | 运行中 |
| completed | 已完成 |
| cancelled | 已取消 |
