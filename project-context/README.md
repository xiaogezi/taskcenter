# ReqRadar 项目上下文库

## 一句话说明

ReqRadar（需求雷达）的 Obsidian 项目上下文库，用于长期存储项目知识。

## 目录结构

```text
project-context/
├── 00-项目概览/    # 项目基本信息
├── 10-架构与设计/  # 系统架构
├── 20-规范/        # 开发规范
├── 30-决策/        # 决策记录
├── 40-经验与问题/  # 经验沉淀
├── 50-当前状态/    # 进度跟踪
├── 60-任务会话/    # 任务记录
├── 70-术语与索引/  # 入口索引
├── 90-Agent待审核/ # 待确认内容
├── 99-归档/        # 已废弃内容
├── templates/      # 文档模板
└── attachments/    # 附件
```

## 使用方式

1. 用 Obsidian 打开 `project-context` 目录
2. 从 [[70-术语与索引/项目上下文索引]] 开始浏览
3. 使用双向链接跳转相关文档

## 状态说明

- 草稿：初始创建，未确认
- 待审核：等待人工确认
- 已确认：已确认内容
- 已废弃：已归档内容
