# 经验与问题

## 一句话结论

此目录用于记录 ReqRadar 项目开发过程中的成功经验、Bug 经验、失败尝试和已知问题。

## 子目录

```text
40-经验与问题/
├── 成功经验/    # 可复用的成功做法
├── Bug经验/     # Bug 记录和解决方案
├── 失败尝试/    # 失败方案和教训
└── 已知问题/    # 待解决的问题
```

## 经验列表

| 编号 | 经验标题 | 类型 | 状态 |
|------|----------|------|------|
| - | 暂无已记录经验 | - | - |

## 经验格式

每条经验记录应包含：

- 一句话结论
- 使用场景
- 具体做法
- 为什么有效
- 不适用场景
- 验证依据

## Bug 格式

每条 Bug 记录应包含：

- 一句话结论
- 现象
- 触发条件
- 根因
- 采用方案
- 失败方案
- 验证方式
- 防复发措施
