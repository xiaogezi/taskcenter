# 开发规范

## 一句话结论

ReqRadar 遵循本地优先、只读 Codex 会话、不上传聊天内容的安全边界。

## 技术规范

### Node.js 版本
- 要求：>=22.13.0

### 前端
- Next.js 16.2.6
- React 19.2.6
- TypeScript
- Tailwind CSS

### 后端/脚本
- ESM 模块（.mjs）
- Zod 校验
- Drizzle ORM

### 数据存储
- JSONL 文件（任务事件）
- JSON 文件（需求基线）

## 安全规范

### 必须遵守

#### Codex 会话访问
- **只读**访问 `~/.codex/sessions/**/*.jsonl`
- **只读**访问 `~/.codex/session_index.jsonl`
- **不读取** `~/.codex/auth.json`
- **不读取** API Key、Cookie

#### 数据处理
- **不上传**聊天内容到远端
- 默认不提供远端部署
- 新建 Session 使用官方 SDK

#### Session 投递
- 新建模式：使用 `@openai/codex-sdk`
- 原 Session 模式：使用本地 CLI
- 不读取或保存认证信息
- 只有本地 JSONL 确认消息和 turn 后才进入运行状态

## 代码规范

### 文件命名
- 脚本：`.mjs` 后缀
- 组件：`.tsx` 后缀
- 样式：`.css` 后缀

```

├── app/        # 前端页面

```

```
├── dashboard.json           # 看板数据

├── task-events.jsonl        # 任务事件日志
├── task-ledger.json         # 任务账本
└── session-selection.json   # 会话选择配置
```

## 验证规范

### Agent 任务验证
- 任务验证基于证据（代码/测试）
- **不接受** Agent 自称 verified
- 状态 verified 只能由人工确认

### 需求验证
- verified：有代码/测试证据
- partial：部分实现
- missing：未实现
- needs_validation：待验证
- untriaged：待整理

## MCP 工具规范

### 工具列表
- `reqradar_session_register` - 注册 Session
- `reqradar_task_create` - 创建任务
- `reqradar_task_update` - 更新任务
- `reqradar_task_report` - 上报结果
- `reqradar_task_query` - 查询账本

### 状态转换
```
planned → in_progress → done_claimed → verified
                ↓
             blocked
                ↓
            cancelled
```

### 幂等性
- 任务事件通过 `event_id` 去重
- 重复事件不重复处理
