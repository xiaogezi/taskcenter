# 模块地图

## 一句话结论

ReqRadar 分为前端看板、同步脚本、MCP Server、控制服务和任务账本五个核心模块。

## 模块概览

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   前端看板    │────▶│  控制服务    │────▶│  任务账本    │
│  (Next.js)   │     │ (HTTP API)   │     │  (JSONL)     │
└──────────────┘     └──────┬───────┘     └──────────────┘
                            │
                            ▼
                     ┌──────────────┐
                     │  同步脚本    │
                     │ (Codex 读取) │
                     └──────┬───────┘
                            │
                            ▼
                     ┌──────────────┐
                     │ Codex 会话   │
                     │  (只读)      │
                     └──────────────┘

┌──────────────┐
│  MCP Server  │◀──── Agent 调用
│ (任务协议)    │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  任务账本    │
└──────────────┘
```

## 模块详情

### 1. 前端看板

**位置**: `app/`

**职责**:
- 渲染需求看板
- 展示需求状态
- 支持会话选择
- 提供手动同步入口

**主要文件**:
- `app/page.tsx` - 主页面
- `app/session-groups.mjs` - 会话分组
- `app/task-session-display.mjs` - 任务匹配

**技术栈**:
- Next.js 16.2.6
- React 19.2.6
- TypeScript
- Tailwind CSS

### 2. 同步脚本

**位置**: `scripts/sync-codex.mjs`

**职责**:
- 读取 Codex 会话文件
- 提取需求和质量
- 生成看板数据
- 写入 `data/dashboard.json`

**依赖**:
- `~/.codex/sessions/**/*.jsonl`
- `~/.codex/session_index.jsonl`

### 3. MCP Server

**位置**: `scripts/reqradar-mcp.mjs`

**职责**:
- 提供 Agent 任务协议工具
- 验证任务状态转换
- 持久化任务事件

**工具列表**:
- `reqradar_session_register` - 注册 Session
- `reqradar_task_create` - 创建任务
- `reqradar_task_update` - 更新任务
- `reqradar_task_report` - 上报结果
- `reqradar_task_query` - 查询账本

### 4. 控制服务

**位置**: `scripts/control-server.mjs`

**职责**:
- 本地 HTTP API
- Session 投递管理
- 健康检查

**端点**:
- `GET /health` - 健康检查
- `POST /sync` - 触发同步
- `GET/POST /session-selection` - 会话选择
- `GET/POST /dispatches` - 投递记录
- `GET/POST /tasks` - 任务管理
- `POST /task-events` - 任务事件

**监听**: `127.0.0.1:3001`

### 5. 任务账本

**位置**: `scripts/task-ledger.mjs`

**职责**:
- 任务状态持久化
- 事件幂等处理
- 状态转换验证

**存储**:
- `data/task-events.jsonl` - 事件日志
- `data/task-ledger.json` - 当前状态

**状态**:
- planned - 计划中
- in_progress - 进行中
- blocked - 阻塞
- done_claimed - 声称完成
- verified - 已验证
- cancelled - 已取消
- removed - 已移除

## 模块依赖关系

```text
前端看板 ──读取──▶ data/dashboard.json
    │
    └──调用──▶ 控制服务

控制服务 ──调用──▶ 同步脚本
    │
    └──读写──▶ 任务账本

MCP Server ──读写──▶ 任务账本

同步脚本 ──只读──▶ Codex 会话
    │
    └──写入──▶ data/dashboard.json
```
