# ReqRadar 首次项目盘点报告

## 1. 项目一句话说明

ReqRadar（需求雷达）是一个本地运行的 Codex 任务需求看板，从本机 Codex 会话中只读提取需求，分开展示"声称完成"和"有证据的验收状态"。

## 2. 项目目标

- 按 Codex 任务聚合用户提出的需求
- 过滤无需求消息，展示验收状态
- 关联人工维护的代码证据与验收缺口
- 支持新建或续办 Session 来推进"部分完成"需求
- 提供任务账本和 MCP 工具供 Agent 使用

## 3. 主要用户或服务对象

- 使用 Codex CLI 的开发者
- 需要追踪多个 Codex 任务需求的用户
- 需要 Agent 遵守任务协议的项目

## 9. 已发现的规范

### 安全边界（来自 AGENTS.md）
- 只读访问 `~/.codex/sessions/**/*.jsonl` 和 `~/.codex/session_index.jsonl`
- 不读取 `~/.codex/auth.json`、API Key、Cookie
- 不写入 Codex 目录
- 不上传聊天到远端
- 默认不提供远端部署

### Agent 任务协议（来自 README.md）
- `reqradar_session_register` - 注册 Session
- `reqradar_task_create` - 创建任务（修改代码前调用）
- `reqradar_task_update` - 更新任务进度
- `reqradar_task_report` - 上报任务结果
- `reqradar_task_query` - 查询任务账本

### 任务状态
- planned、in_progress、blocked、done_claimed、verified、cancelled、removed

### 需求状态
- verified、in_progress、partial、missing、needs_validation、untriaged
