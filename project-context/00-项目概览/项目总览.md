# 项目总览

## 一句话说明

ReqRadar（需求雷达）是一个本地运行的 Codex 任务需求看板，从本机 Codex 会话中只读提取需求，分开展示"声称完成"和"有证据的验收状态"。

## 项目目标

- 按 Codex 任务聚合用户提出的需求
- 过滤"继续""可以"等无需求消息
- 展示已验收、部分实现、未实现、待验证和待整理状态
- 关联人工维护的代码证据与验收缺口
- 支持 Agent 通过 MCP 工具遵守任务协议

## 用户或服务对象

- 使用 Codex CLI 的开发者
- 需要追踪多个 Codex 任务需求的用户
- 需要 Agent 遵守任务协议的项目
- 使用 Claude Code 或 Codex Desktop 的团队

## 核心价值

- 需求状态可视化：清晰展示需求完成度
- Agent 任务协议：通过 MCP 工具规范 Agent 行为
- 本地优先：数据不上传远端，保护隐私
- 任务账本：持久化任务状态，支持断点续办

## 项目范围

### 包含

- Codex 会话需求提取和展示
- 需求状态追踪（verified/partial/missing 等）
- 任务账本和 MCP 工具
- 本地 Session 投递服务
- macOS 桌面入口

### 不包含

- 远程部署和云端存储
- 多用户协作
- 向量搜索
- 自动修改正式规范

## 核心模块

| 模块 | 职责 |
|------|------|
| 前端看板 | Next.js 页面，展示需求状态 |
| 同步脚本 | 读取 Codex 会话，生成看板数据 |
| MCP Server | 提供 Agent 任务协议工具 |
| 控制服务 | 本地 HTTP 服务，处理 Session 投递 |
| 任务账本 | 持久化任务状态和事件日志 |
