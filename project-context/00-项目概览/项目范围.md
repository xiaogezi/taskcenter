# 项目范围

## 一句话结论

ReqRadar 是本地 Codex 任务需求看板，专注于需求提取、状态展示和 Agent 任务协议，不提供远程部署或多用户协作。

## 功能边界

### 核心功能（包含）

#### 需求管理
- 从本地 Codex 会话提取需求
- 按任务 ID 聚合需求
- 过滤无需求消息
- 需求状态分类展示

#### 状态追踪
- verified：有代码/测试证据的验收
- partial：部分实现
- missing：未实现
- needs_validation：待验证
- untriaged：待整理

#### Agent 支持
- MCP 工具：session_register, task_create, task_update, task_report, task_query
- 任务账本：持久化任务状态
- 事件日志：JSONL 格式记录

#### Session 管理
- 新建 Session（注入压缩上下文）
- 续办原 Session
- 本地投递队列
- 状态：等待、投递、运行、结束

#### 用户界面
- Web 看板（Next.js）
- macOS 桌面入口
- 手动选择会话范围

### 明确不包含

- 远程部署和云端存储
- 多用户协作和权限管理
- 向量搜索和语义检索
- 自动修改正式规范
- 自动批准知识
- 多 Agent 并发支持

## 数据边界

### 读取范围
- `~/.codex/sessions/**/*.jsonl`
- `~/.codex/session_index.jsonl`

### 不读取
- `~/.codex/auth.json`
- API Key
- Cookie

### 写入范围
- 本地 `data/` 目录
- 本地 Session 投递（需确认）

## 安全边界

- 不上传聊天内容到远端
- 不读取认证信息
- 新建 Session 使用官方 SDK
- 原 Session 模式使用本地 CLI

## 适用场景

### 适合
- 单用户本地开发
- Codex 任务追踪
- Agent 任务协议

### 不适合
- 多人协作
- 云端部署
- 大规模团队使用
